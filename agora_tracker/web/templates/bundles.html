Bundled activity

The trades of clustered wallets, collapsed to one action per cluster and token. Where the Activity tab shows every wallet separately, this view counts a cluster once, using the membership that was valid when each trade happened (later merges and splits never rewrite it). Amounts are verified or estimated HYPE, kept apart; a leg without an amount is counted, never valued at zero.
